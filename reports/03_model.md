# 3단계 모델링 결과

재현: `python3 src/model.py`, `python3 src/risk_score.py`

## 모델 성능 (5-fold CV ROC-AUC, 학습 80%)
| 피처셋 | 로지스틱 | GBM |
|---|---|---|
| 전체 (`avg_watch` 포함) | 0.966 ± 0.003 | 0.9999 ± 0.0001 |
| `avg_watch` 제외 (원천 변수만) | 0.964 ± 0.004 | 0.9992 ± 0.0004 |

홀드아웃 20% (`avg_watch` 제외): 로지스틱 AUC 0.961 / 정확도 88.2%, GBM AUC 0.9998 / 정확도 99.2%.

- 파생 변수 `avg_watch_time_per_day` 를 빼도 성능 차이가 거의 없다 → 원천 변수만 쓴다.
- GBM이 거의 완벽하다 → 실제 데이터에서는 불가능한 수준. **라벨이 규칙으로 생성됐다**는 EDA 가설과 일치한다.

## 무엇이 이탈을 결정하나 (GBM 순열 중요도, AUC 감소량)
`watch_hours` 0.28 > `last_login_days` 0.21 > `number_of_profiles` 0.05 > `subscription_type` 0.03 > `payment_method` 0.03. 성별·지역·기기·장르·나이는 **0** (`reports/figures/importance.png`).

## 라벨 규칙 역추정
얕은 의사결정나무가 정확히 5h·20h·7일·30일·프로필 3.5에서 분기 → 이진 플래그 점수합 가설을 세워 검증.

| 플래그 | 점수 |
|---|---|
| 시청 5시간 미만 | +2 |
| 마지막 접속 30일 초과 | +2 |
| Basic 요금제 | +1 |
| Crypto·Gift Card 결제 | +1 |
| 프로필 3개 이하 | +1 |
| 마지막 접속 7일 미만 | −1 |
| 시청 20시간 초과 | −2 |

**점수 ≥ 3 → 이탈** 규칙이 라벨을 **96.5%** 재현한다. 점수 ≤1 이탈률 0%, 2점 7%, 3점 88%, 4점 이상 99.5~100%.
남은 3.5%는 2~3점 경계에 몰려 있다 (실제 생성식은 연속값이나 다른 가중치일 수 있음 → 확인 불가).

## 시사점
- 이 데이터에서 "모델 성능"은 자랑할 거리가 아니다. **해석 가능한 7개 규칙**이 더 좋은 결과물이다.
- 점수는 그대로 세그먼트 기준으로 쓸 수 있다 → 4단계에서 점수대별 고객 규모와 액션을 정리한다.
