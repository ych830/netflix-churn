# 1단계 EDA 결과

재현: `python3 src/eda.py` → 그림은 `reports/figures/`

## 데이터 품질
- 5,000행 × 14열, 결측 0, 중복 0, `customer_id` 고유.
- 이탈률 50.3% → 클래스 균형. (실제 서비스 이탈률(월 수 %)보다 훨씬 높음 → **합성 데이터로 판단**)
- 범주형 변수가 거의 균등 분포 (성별·지역·기기·장르·결제수단 각 1/n 근처) → 역시 합성 데이터 특징.

## 구조적 발견 (모델링 전에 반드시 처리)
| 발견 | 근거 | 처리 |
|---|---|---|
| `monthly_fee` = `subscription_type` 의 1:1 함수 (8.99/13.99/17.99) | 요금제별 요금 종류 1개 | 둘 중 하나만 사용 |
| `avg_watch_time_per_day` = `watch_hours / (last_login_days + 1)` | 최대 오차 0.005 | 파생 변수. 정의(“하루 평균”)와 계산식이 맞지 않으니 의미 해석 주의 |
| 시청시간·마지막 접속일에 **계단형 임계값** | 30일, 5시간, 20시간에서 이탈률 급변 | 규칙 기반으로 라벨을 만든 데이터일 가능성 높음 → 모델 성능이 비현실적으로 높게 나올 수 있음 |

## 이탈과의 관계 (강한 순)
| 변수 | 결과 | 크기 |
|---|---|---|
| `avg_watch_time_per_day` | 유지 0.72 vs 이탈 0.12 (중앙값) | 단변수 AUC 0.92 |
| `watch_hours` | 유지 13.9h vs 이탈 4.1h. ≤5h 이탈 83~86%, >20h 이탈 4.5% | AUC 0.81 |
| `last_login_days` | 유지 19일 vs 이탈 41일. ≤7일 13%, 30일 초과 75% | AUC 0.77 |
| `number_of_profiles` | 1~3개 57~59%, 4~5개 38~41% (3→4에서 급변) | V 0.19 |
| `subscription_type` | Basic 62%, Standard 45%, Premium 44% | V 0.16 |
| `payment_method` | Crypto 60%, Gift Card 58% vs 카드 44% | V 0.14 |
| 성별·지역·기기·장르·나이 | 차이 없음 (p > 0.3) | 무관 |

## 해석 요약
1. **이탈 = 참여도 하락.** 적게 보고 오래 접속 안 한 고객이 나간다. 가장 강한 신호.
2. **약정 성격이 약한 고객이 더 나간다.** Basic 요금제, 비정기 결제수단(Crypto·Gift Card = 자동 갱신 없음 추정), 프로필 3개 이하.
3. **인구통계·취향(장르·기기·지역)은 이탈과 무관.** 타깃팅에 쓸 가치 낮음.

## 주의
- 데이터에 **시점 정보가 없다** (가입일, 관측 시점, 이탈 시점 모두 없음). `last_login_days` 가 이탈 *후에* 커진 결과일 수 있다 (역인과/누수). “30일 미접속이면 이탈 위험”이라는 예측 규칙은 실제 운영에서 이탈 *전에* 측정한 값이어야 의미가 있다.
