# 2단계 기획

## 목적 (C: 예측 + 전략)
1. 이탈 여부를 예측하는 모델을 만들고, **어떤 변수가 얼마나** 이탈을 설명하는지 정량화한다.
2. 그 결과로 고객을 세그먼트로 나누고, 세그먼트별 **이탈률·규모·대응 액션**을 제안한다.

## 가정 (사용자 미확정 → 바뀌면 수정)
- 산출물: 포트폴리오용 분석 보고서 (마크다운 + 그림, 필요 시 웹 페이지)
- 데이터는 합성 데이터로 보고, 결과를 "실제 Netflix 사실"로 주장하지 않는다.

## 범위
- 포함: 전처리, 로지스틱 회귀(기준선·해석용) vs 그래디언트 부스팅(성능용), 변수 중요도, 규칙 기반 세그먼트, 액션 제안
- 제외: 하이퍼파라미터 대규모 탐색, 딥러닝, 배포/API (요청 시 추가)

## 피처 결정 (EDA 근거)
- 제거: `customer_id`(식별자), `monthly_fee`(요금제와 1:1 중복)
- `avg_watch_time_per_day`: 다른 두 변수의 파생값 → **포함/제외 두 버전을 비교**해 영향 확인
- 범주형: 원-핫 인코딩. 수치형: 로지스틱에만 표준화.

## 성공 기준 (검증 가능)
| 항목 | 기준 |
|---|---|
| 평가 방식 | 계층 5-fold 교차검증 ROC-AUC (평균±표준편차) + 20% 홀드아웃 테스트 |
| 기준선 대비 | 모델이 다수 클래스 기준선(AUC 0.5) 및 단일 변수(`avg_watch` AUC 0.92)보다 높아야 의미 있음 |
| 해석 | 순열 중요도 상위 변수가 EDA 결과와 일관되는지 확인 |
| 세그먼트 | 전체 고객 100%가 정확히 하나의 세그먼트에 속하고, 세그먼트별 이탈률·인원 표 제시 |
| 재현성 | `python3 src/*.py` 로 모든 숫자·그림 재생성 |
